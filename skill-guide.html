SKILL GUIDE

Complete ability reference for all classes

⚔️ WARRIOR SKILLS

🛡️ Shield Skills

  • Shield Bash - Stun enemies with shield
  • Shield Wall - Block incoming damage
  • Throw Shield - Ranged shield attack

⚔️ Sword Skills

  • Cleave - AoE sword attack
  • Pommel Strike - Daze enemy
  • Whirlwind - Spin attack all nearby

💪 Rage Skills

  • Berserk - Increased damage, lifesteal
  • War Cry - Draw aggro
  • Battle Cry - Team damage buff

🛡️ Defense Skills

  • Parry - Counterattack after block
  • Bastion - Damage reduction
  • Fortress - Immunity frames

🏹 ROGUE SKILLS

🗡️ Dagger Skills

  • Backstab - High damage from behind
  • Flurry - Rapid attacks
  • Garrote - Silent kill

🏹 Bow Skills

  • Piercing Shot - Arrow through enemies
  • Snipe - Long range precise
  • Arrow Storm - AoE arrow rain

💨 Stealth Skills

  • Stealth - Become invisible
  • Shadow Step - Teleport behind
  • Smoke Bomb - Escape tool

☠️ Poison Skills

  • Poison Blade - Apply DoT
  • Toxic Cloud - AoE poison
  • Deadly Venom - Burst poison

🔮 MAGE SKILLS

🔥 Fire Skills

  • Fireball - AoE fire burst
  • Flame Wave - Cone attack
  • Meteor - Massive AoE

❄️ Ice Skills

  • Frost Bolt - Single target
  • Ice Storm - Slow field
  • Glacial Spike - Damage + freeze

⚡ Lightning Skills

  • Chain Lightning - Jump between
  • Thunderstorm - Area denial
  • Static Discharge - Burst damage

💀 Necromancy

  • Summon Skeleton - Minion
  • Death Beam - Lifesteal ray
  • Curse - Weaken enemy

⭐ ULTIMATE ABILITIES

⚔️ Warrior Ultimate

Devastating Strike - Massive single target damage

🏹 Rogue Ultimate

Death Mark - Execute on marked target

🔮 Mage Ultimate

Arcane Explosion - Massive AoE magic damage

Shield Bash → Cleave → Whirlwind → Berserk

Rogue Combo

Stealth → Backstab → Flurry → Garrote

Mage Combo

Ice Storm → Fireball → Chain Lightning

Team Combo

Aggro → CC → Burst → Cleanup
